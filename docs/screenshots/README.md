# Screenshots

This directory is intentionally empty in the published repository.

Drop screenshots or a short screen recording here before publishing, then
reference them from the README:

| File | What it shows |
| ---- | ------------- |
| `home.png` | Homepage — featured + latest-arrivals sections |
| `product.png` | Product detail page (SSG + ISR) |
| `shop-filters.png` | Shop grid with the advanced filter panel |
| `login.png` | Sign-in flow |

Embed them like so:

```md
![Homepage](docs/screenshots/home.png)
```

**Note:** all product imagery in this showcase is a generated placeholder, so
these screenshots show illustrative layout only — not the real catalogue.
